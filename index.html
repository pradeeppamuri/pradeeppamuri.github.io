DocuMind: Offline AI Document Assistant

Privacy-first

Desktop app that finds files by the words inside them and runs an on-device AI assistant for Q&A with page citations, study notes, flashcards and quizzes. Runs 100% offline.

  • Content-based file search using SQLite FTS5 with BM25 ranking and a 0 to 100 relevance score, with incremental indexing.
  • Offline RAG pipeline: PDF/DOCX/TXT extraction, chunking, passage retrieval and answers with page-level citations.
  • On-device LLM engine (llama.cpp with quantized Qwen2.5 GGUF models), in-app download with resume and cancel, GPU (Vulkan) when available.
